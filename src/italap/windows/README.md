Az operációs rendszer teremti meg a kapcsolatot a számítógép hardvere, a programok és a felhasználó között. Ez a témakör a Windows telepítésének és alapvető konfigurálásának kérdéseivel foglalkozik. A telepítés előkészítéséhez az eszköz követelményeit, a háttértár használatát és az adatok megőrzését is át kell gondolni. A beállítások között a felhasználói fiókok, az illesztőprogramok, a hálózati kapcsolat és a frissítések is fontos szerepet kapnak. A cél egy olyan alapozó szemlélet kialakítása, amellyel érthetővé válik a rendszer üzembe helyezése és mindennapi kezelése.
