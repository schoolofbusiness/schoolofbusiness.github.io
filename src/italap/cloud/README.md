A virtualizáció lehetővé teszi, hogy egy fizikai számítógépen több elkülönített rendszer működjön. A tananyag bemutatja a virtuális gépek és a virtualizációt biztosító szoftverek szerepét. A felhőtechnológiáknál azt vizsgáljuk, hogyan vehetők igénybe informatikai erőforrások és szolgáltatások hálózaton keresztül. Megismerheted a különböző szolgáltatási modelleket, valamint a Windows és a Linux virtuális környezetben történő használatának alapjait. A leckék segítenek összehasonlítani a helyi és a felhőben elérhető megoldások feladatait, előnyeit és korlátait.
