A CSS határozza meg, hogyan jelenjen meg a HTML-ben leírt tartalom a böngészőben. A leckék a stíluslapok és a kijelölők alapjaitól a színek, mértékegységek, hátterek és szövegek formázásáig vezetnek. A dobozmodell megértésével átláthatod, hogyan hatnak a méretek, a margók és a szegélyek egy elem megjelenésére. A táblázatformázási példákban a cellák elrendezését, igazítását és színezését is gyakorolhatod. A záróprojektben egy szakköri bemutatkozó oldal elkészítésével alkalmazhatod együtt a tanultakat.
