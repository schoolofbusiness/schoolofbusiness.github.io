A Python jól olvasható nyelv, amellyel a programozás alapvető fogalmait gyakorolhatod. A tananyag a fejlesztői környezet megismerésétől a változókon és az adattípusokon át a vezérlési szerkezetekig vezet. Később listákkal, szótárakkal, függvényekkel, modulokkal és objektumokkal is foglalkozunk. A fájlkezelési példák megmutatják, hogyan őrizhetők meg és dolgozhatók fel a programon kívül tárolt adatok. A megértést az segíti legjobban, ha a kódrészleteket magad is futtatod, módosítod, és megpróbálod előre megjósolni az eredményüket.
