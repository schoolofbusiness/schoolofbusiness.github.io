A programozás során egy feladat megoldását pontos, végrehajtható lépésekre bontjuk. Ebben a témakörben a Python programozással és a weboldalak készítésének alapjaival ismerkedhetsz meg. A HTML a weboldal tartalmát és szerkezetét adja, a CSS a megjelenését alakítja, a JavaScript pedig működéssel egészíti ki. A példák feldolgozásakor érdemes saját változatokat készíteni, kipróbálni őket, és megfigyelni a módosítások hatását. Az alábbi részek közül választva a programozási gondolkodást és a webes ismereteket egymásra építve gyakorolhatod.
