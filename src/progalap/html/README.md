A HTML segítségével megadhatod egy weboldal tartalmát és annak logikus szerkezetét. A leckék bemutatják a dokumentum alapvázát, a címsorokat, a bekezdéseket és a különböző listákat. Megtanulhatod, hogyan készíthetsz hivatkozásokat, hogyan illeszthetsz be képeket, és hogyan építhetsz táblázatokat. A példákban az elemek jelentésére, az áttekinthető forráskódra és a hozzáférhető tartalomra is figyelünk. A témakör végén az itt tanultakból önálló, többféle tartalmi elemet használó HTML-oldalt állíthatsz össze.
